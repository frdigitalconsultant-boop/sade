# Menu sade.

Halaman menu & pemesanan Sade FnB (pesan via WhatsApp, split bill, QR per meja).

- `index.html` — halaman menu. Harga, nomor WhatsApp, jumlah meja ada di bagian **PENGATURAN**.
- `img/` — satu foto per menu, nama file sesuai menu (mis. `paket-np-dada.jpg`).
  Ganti foto = timpa file dengan nama yang sama.
- Kartu QR meja: buka `…/#kartu-qr`. Link per meja: `…/#meja-3`.

Hosting: Vercel (otomatis update setiap ada push ke `main`).
Alamat: https://sade-one.vercel.app/
